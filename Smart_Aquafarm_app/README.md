# WaterWise AI — Updated UI Prototype

ต้นแบบเว็บแอปที่ปรับ UI ตามภาพตัวอย่างที่ผู้ใช้ส่งมา โดยมี 4 หน้าหลัก:
0. กรอกข้อมูลผู้ใช้ครั้งแรก
1. หน้าหลัก
2. ปริมาณน้ำที่จะได้รับ
3. คุณภาพน้ำและความเสี่ยง

## ฟังก์ชัน
- First-time onboarding: ชื่อ, ตำแหน่ง, พื้นที่เกษตร, ประเภทพืช, ความจุแหล่งน้ำ, น้ำปัจจุบัน, อัตราใช้น้ำ, พื้นที่รับน้ำฝน
- เก็บข้อมูลผู้ใช้ด้วย localStorage
- Dashboard แสดงน้ำคงเหลือและจำนวนวันที่ใช้ได้
- พยากรณ์ฝน 7 วัน
- คำนวณ/แสดงน้ำที่ใช้ได้จากฝนในรูปแบบต้นแบบ
- หน้าปริมาณน้ำ 7 วัน พร้อมสลับมุมมองระยะยาว
- หน้าคุณภาพน้ำและแนวโน้มความเสี่ยง
- ดูรายละเอียดรายวันผ่าน modal

## หมายเหตุ
โค้ดนี้เป็น Prototype ฝั่ง Frontend. ส่วน AI, API สภาพอากาศ, GPS จริง, Dataset และ Backend ยังไม่ได้เชื่อมต่อ
และค่าความเสี่ยงในหน้าคุณภาพน้ำเป็นข้อมูลตัวอย่างสำหรับ UI เท่านั้น
